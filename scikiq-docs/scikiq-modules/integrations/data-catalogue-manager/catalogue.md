# Catalogue

* Data Catalogs are one of the core components of the ScikIQ Business Data Platform.&#x20;
* It helps Organizations to see remarkable changes in the speed and quality of data analysis. ScikIQ data catalogs offer a fast and inexpensive way to inventory and classify the organization’s increasingly distributed and disorganized data assets and map their information supply chains to limit data sprawl.&#x20;
* Our Data Catalogs use ML models to simplify, inform, augment, and even automate various metadata management tasks.
* A Data Catalog is a collection of metadata, combined with data management and search tools, that helps analysts and other data users find the data that they need, serves as an inventory of available data, and provides information to evaluate fitness data for intended uses.&#x20;
* The data catalog provides context to enable data stewards, data/business analysts, data engineers, data scientists, and other line of business (LOB) data consumers to find and understand relevant datasets for the purpose of extracting business value.&#x20;
* Modern machine-learning-augmented data catalogs automate various tedious tasks involved in data cataloging, including metadata discovery, ingestion, translation, enrichment, and the creation of semantic relationships between metadata.
* These next-generation data catalogs can therefore propel enterprise metadata management projects by allowing business users to participate in understanding, enriching, and using metadata to inform and further their data and analytics initiatives.

### Purpose of the Catalogs<br>

* ScikIQ provides the option to completely catalog your data while making it available across the organization as data assets.Comment
* The cataloging process is only available to a data steward role within ScikIQ who can identify critical data assets and assign ownership to Data owner roles. An Admin can accordingly map which users will be responsible for both the maintenance (Data Owners) and the governance (Data Steward) within the organization to have proper segregation of duties.

### How to create a catalog in ScikIQ

* When ScikIQ is installed for the first time, it comes with a pre-configured Enterprise Catalogue.

<figure><img src="../../../.gitbook/assets/image (1021).png" alt=""><figcaption></figcaption></figure>

* Enterprise Catalogue is the highest level of data cataloging which segregates organization-level entities and divisions from Enterprise. These are typically used for organizing assets such as Master Data etc
  * Let’s say ABC PLC has implemented an MDM tool where Customers and Products are mastered in Central MDM solution across the Enterprise.  They want all divisional groups and LE to subscribe to this Master Data using a subscription Contract.

<figure><img src="../../../.gitbook/assets/image (1022).png" alt=""><figcaption></figcaption></figure>

* ScikIQ also offers functionality to define a Custom Catalogue for managing and organizing assets. These user-defined catalogues are created via ScikIQ Screen with ownership assigned only to Data Owners.

<figure><img src="../../../.gitbook/assets/image (1023).png" alt=""><figcaption></figcaption></figure>

* Catalogue owners can only be assigned from a predefined set of users who have the data owner role.
* Delegates can be assigned who can take over the governance when the owners are unavailable

<figure><img src="../../../.gitbook/assets/image (1024).png" alt=""><figcaption></figcaption></figure>

* The catalogue once created can be edited by the catalogue owner. All the assets assigned to a catalogue can also be viewed directly from this page
