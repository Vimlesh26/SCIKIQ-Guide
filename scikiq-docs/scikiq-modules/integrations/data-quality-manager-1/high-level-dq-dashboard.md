# High Level - DQ Dashboard

* This Reporting dashboard gives a consolidated 360-degree view of a summary of data quality checks applied at various organizational levels. It provides a health check on a catalog, domain, sub-domain, or at an overall entity level. It gives the high-level gaps that need to be addressed in each area for the respective owners.&#x20;
*   This helps stakeholders with a quick view of the quality assurance state of the system and works on the following fundamentals

    * Information of Data Quality Measures - Gives a summary level information of the data quality set up in the system
    * Knowledge of the current state of the system - a 360-degree view of the failed and passed measures.
    * At a Glance Dashboard - Flexibility to get a quick overview of the system health check and ability to slice and dice data by catalog, domain, sub-domain, etc.
    *   Trends and month-over-month patterns for fail and success quality percentages.


    * Bring in Stakeholders - Find and bring in key stakeholders to understand data collection, storage, process and hence increase accountability


*   Within ScikIQ we have 3 dashboards to help stakeholders understand overall data quality structural diagnostics and data quality assessment reliability.

    * Overall Summary
    * Summary Failed DQ
    * Failed Measure Analysis


* Each dashboard can be filtered over an entity, catalog, or domain for a particular period
