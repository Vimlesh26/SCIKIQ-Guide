# VS Meta Data Manager

* If enterprise data — with its large volumes, diverse types, varied formats, and distributed locations — is to be managed strategically, its metadata must be suitably defined and used.
* At its core, metadata is _a set of data that describes and gives information about other data._
* According to Gartner, a good metadata management approach must provide visibility across different sources and data management initiatives and bring nontechnical business users into the fold. This will result in a collaborative, active metadata management process.
