# Semantic Modelling

***

### Overview

{% tabs %}
{% tab title="About Semantic Modeling" %}
Semantic modeling is the process of creating a structured representation of data that adds meaning and context to raw data. It defines how data elements relate to each other, often in a way that's closer to business understanding than just technical definitions.
{% endtab %}

{% tab title="Importance" %}
The semanctic model is important because of:

* **Business-Friendly Data Layer** – Semantic modeling bridges the gap between complex raw data structures and business terminology, making data easier to understand and use for business users.
* **Data Reusability** – Once a semantic model is created, it can be reused across multiple reports, dashboards, and analytical applications, eliminating the need for users to understand underlying SQL queries or database structures.
* **Consistency and Accuracy** – It ensures that key business metrics, such as Revenue, Profit, or Active Users, are defined and calculated consistently across the organization, reducing reporting discrepancies.
* **Enables Self-Service BI** – By presenting data in a user-friendly format, semantic models empower non-technical users to independently explore, analyze, and visualize data using tools such as Power BI, Tableau, and Looker.
* **Supports Data Governance** – Semantic modeling helps enforce standardized naming conventions, business definitions, and calculation logic, ensuring reliable and governed reporting across all dashboards and reports.
{% endtab %}

{% tab title="Modules" %}
Semantic Model includes the below modules:

* **Entities** (Tables such as Customer, Product, Sales)
* **Attributes** (Columns)
* **Relationships** (Koins/Foreign keys)
* **Hierarchies** (e.g., Year > Quarter > Month)
* **Measures** (Calculated metrics such as Revenue, Margin)
* **Metadata** (descriptions, units, format, etc.)
{% endtab %}
{% endtabs %}
