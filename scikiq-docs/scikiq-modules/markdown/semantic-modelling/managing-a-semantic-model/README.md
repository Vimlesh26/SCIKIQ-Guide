# Managing a Semantic Model

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

Once a semantic model is created, it is listed on the **Semantic Models** page, which serves as a centralized repository for managing all semantic models within the system. From this page, you can view the details and structure of a model, modify its configuration to accommodate changing business requirements, or delete models that are no longer needed. This enables efficient management, maintenance, and governance of semantic models throughout their lifecycle.

***

### **Manage Semantic Model**

Depending on your requirements, you can perform the following tasks on a Semantic Model:

{% tabs %}
{% tab title="View Semantic Model" %}
**Overview**

The **View** option allows you to open and examine an existing semantic model without making any changes to it. It provides access to the model's entities, relationships, KPIs, Data Quality (DQ) Rules, and other associated configurations. This option is useful for reviewing the model structure, validating its contents, and understanding how the model has been designed. &#x20;

***

**Procedure**

The below step-by-step instructions help you understand how to view a semantic model:

1. On the SCIKIQ left navigation bar, expand **Semantic Modelling**, and then click **Lists**.

<figure><img src="../../../../.gitbook/assets/image (2107).png" alt=""><figcaption></figcaption></figure>

The Semantic Model List page is displayed.

2. On the **Semantic Model List** page, click the **View** icon corresponding to the required model.

<figure><img src="../../../../.gitbook/assets/image (2108).png" alt=""><figcaption></figcaption></figure>

The Semantic Model is displayed.
{% endtab %}

{% tab title="Update a Semantic Model" %}
**Overview**

The **Edit** option allows you to modify an existing semantic model and update its configuration as needed. You can add, remove, or update entities, relationships, KPIs, DQ Rules, and other model components. This option is useful when business requirements change or when enhancements need to be made to the model after its initial creation. &#x20;

***

**Procedure**

The below step-by-step instructions help you understand how to update a semantic model:

1. On the **Semantic Model List** page, click the **Edit** icon corresponding to the required model.

<figure><img src="../../../../.gitbook/assets/image (2109).png" alt=""><figcaption></figcaption></figure>

The Edit page is displayed.

2. On the **Edit** page, make the required modifications, and then click the **Save** button.

The **Semantic Model** is updated as per the changes made.el
{% endtab %}

{% tab title="Delete a Semantic Model" %}
**Overview**

The **Delete** option allows removing semantic models that are no longer required or relevant. This helps maintain a clean and organized list by eliminating outdated or unused semantic models.

***

**Procedure**

The below step-by-step instructions help you understand how to delete a semantic model:

1.  On the **Semantic Model List** page, click the **Delete**

    &#x20;icon corresponding to the required model.

<figure><img src="../../../../.gitbook/assets/image (2113).png" alt=""><figcaption></figcaption></figure>

The Delete message is displayed.

2. On the **Delete** message, click the **OK** button..

The **Semantic Model** is deleted.
{% endtab %}

{% tab title="Hide or Unhide Columns" %}
**Overview**

The **View or Hide a Column** option allows controlling the visibility of columns within a table based on their requirements. It enables displaying only the relevant columns and hide unnecessary information, resulting in a cleaner and more focused view of the data. This feature improves readability and enhances the user experience by reducing visual clutter. It also provides flexibility in customizing the table display according to specific business or reporting needs.

***

**Procedure**

> <mark style="color:red;">**Note:**</mark> On the **Semantic List** page, the column headers displayed in **blue** indicate **visible** columns, whereas the tabs displayed in **grey** represent **hidden** columns.

The below step-by-step instructions help you understand how to view or hide a column:

1. On the **Semantic List** page, if you want to hide a column, click on that column header.&#x20;
2. If you want to view it, click again on the column header.
