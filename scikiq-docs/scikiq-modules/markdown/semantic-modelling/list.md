# List

**Semantic Model List**

Here you can get the list of semantic model that you have created earlier.

<figure><img src="../../../.gitbook/assets/image (1383).png" alt=""><figcaption></figcaption></figure>

**Button Functionalities**

| **Button**                                                                             | **Action Description**                                                                  |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
|  <img src="../../../.gitbook/assets/image (1384).png" alt="" data-size="line">**View** | Opens the model in read-only mode to explore entities, links, and metadata.             |
| ✏️ **Edit**                                                                            | Opens the model editor to update entities, relationships, thresholds, or documentation. |
| 🗑️ **Delete**                                                                         | Prompts a confirmation before permanently deleting the semantic model from the system.  |

**View Button**- This is only for the view purpose for the semantic model that you have created earlier.

<figure><img src="../../../.gitbook/assets/image (1398).png" alt=""><figcaption></figcaption></figure>

**Edit Button** - You can do any related changes in the existing semantic model and then save it.

<figure><img src="../../../.gitbook/assets/image (1396).png" alt=""><figcaption></figcaption></figure>

**Delete Button**- By clicking on delete button, you will get this notification for the particular semantic model.
