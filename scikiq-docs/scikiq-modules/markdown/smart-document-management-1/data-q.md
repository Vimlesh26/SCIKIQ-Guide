# Data Q

**Data Quality** refers to the **degree to which data is accurate, complete, consistent, reliable, and relevant** for its intended purpose. High-quality data enables correct analysis, reporting, and decision-making.

#### **Key Data Quality Dimensions:**

| **Dimension**    | **Description**                                                             |
| ---------------- | --------------------------------------------------------------------------- |
| **Accuracy**     | Data reflects the real-world values correctly (e.g., correct phone numbers) |
| **Completeness** | No missing required values or records                                       |
| **Consistency**  | No contradictions between data across systems or tables                     |
| **Timeliness**   | Data is up-to-date and available when needed                                |
| **Validity**     | Data follows required formats, rules, or business constraints               |
| **Uniqueness**   | No unintended duplicates in records or fields                               |
