# Auto ML Studio

***

### Overview

This page provides an **overview of AutoML Studio** and explains how it helps simplify the process of building and using machine-learning models. The topics covered include **What is AutoML Studio?, Role of AutoML Studio in Data Management, Benefits of AutoML Studio,** and **Overview of the AutoML Workflow**.

Click the **tabs below** to explore each topic and learn more about AutoML Studio, its key benefits, and the typical workflow involved in creating, testing, deploying, and using ML models.

{% tabs %}
{% tab title="What AutoML Studio is" %}
**AutoML Studio** is a platform that helps **creating and using machine-learning models with minimal manual effort**.&#x20;

It automates many complex tasks involved in machine learning, such as preparing data, selecting suitable models, training models, and evaluating their performance.&#x20;

This makes machine learning easier for users who may not have extensive knowledge of programming or data science.
{% endtab %}

{% tab title="Role of AutoML Studio in Data Management" %}
AutoML Studio helps organizations **turn their managed data into useful predictions and insights**. It can work with data from different sources and use that data to build machine-learning models.&#x20;

While data management focuses on organizing, maintaining, and ensuring the quality of data, AutoML helps **analyze that data and use it for predictive purposes**.&#x20;

This supports better and more data-driven decision-making.
{% endtab %}

{% tab title="Benefits of AutoML Studio" %}
AutoML Studio provides several benefits:

* **Saves time** by automating many machine-learning tasks.
* **Reduces manual effort** required to build and test models.
* **Requires less coding**, making machine learning easier for non-technical users.
* **Compares different models** to help identify a suitable model.
* **Improves productivity** by allowing users to build models faster.
* **Supports better decision-making** by generating predictions from available data.
{% endtab %}

{% tab title="Overview of the AutoML Workflow" %}
The AutoML workflow describes the steps involved in **creating and using a machine-learning model**.&#x20;

It generally starts with selecting and preparing the required data, followed by performing **EDA and data profiling** to understand the data.&#x20;

This follow by creating an ML use case, selecting a model and target variable, and **test and compare the model's performance**.&#x20;

Once a suitable model is identified, it can be **deployed and used to generate predictions**.

**In simple terms:**

**Prepare Data → Understand Data → Create ML Use Case → Select Model → Test & Compare → Deploy Model → Generate Predictions**
{% endtab %}
{% endtabs %}
