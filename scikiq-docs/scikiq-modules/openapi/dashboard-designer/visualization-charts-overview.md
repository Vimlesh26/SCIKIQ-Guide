# Visualization Charts Overview

## Overview

The SCiKIQ Designer module enables you to build interactive dashboards by adding various components such as Info Widgets, Pie Charts, Bar Charts, Stacked Charts, and Line Charts. These components help visualize data in different formats, allowing you to analyze trends, compare values, and present key insights effectively based on your requirements.&#x20;

Here is a brief overview about the dashboard components.

| **Chart**                    | **Description**                                                                                                                                                                                                    | **When to use**                                                                                                                                                     | **Example**                                                                                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Info Widget                  | An Info Widget is a simple dashboard element that displays a key metric or single data point—often as a number, small chart, or both—for quick insight at a glance.                                                | You can use it when you want to highlight a single, important metric—such as total sales, revenue, active users, or conversion rate.                                | Total sale: 75,00,000                                                                                                                                                                 |
| Pie Chart                    | A Pie Chart is a circular chart that represents data as proportional slices, with each slice showing a category’s share of the whole, making it ideal for visualizing percentage-based data.                       | A Pie Chart is best used when you want to show how different parts make up a whole, especially when there are only a few categories.                                | An example for this is - if a company’s total sales come from North (40%), South (30%), East (20%), and West (10%), a pie chart clearly shows each region’s contribution at a glance. |
| Horizontal Bar Chart         | A Horizontal Bar Chart displays categories as horizontal bars whose lengths represent their values, making it especially useful for comparing categories clearly, particularly when labels are long                | Use a Horizontal Bar Chart when you want to compare values across different categories, especially if the category names are long or easier to read horizontally.   | <p>An example for this is - comparing sales across regions like North America, Asia Pacific, and the Middle East is clearer in a horizontal layout. </p><p><br></p>                   |
| Vertical Stacked Bar Chart   | A Vertical Stacked Bar Chart displays multiple data series stacked within each vertical bar, allowing you to compare total values across categories while also showing the contribution of each sub-category.      | Use a Vertical Stacked Bar Chart when you want to compare total values across categories and also see how each part contributes to the total                        | An example for this is - showing total sales for each region while breaking it down into product categories like electronics, clothing, and furniture within the same bar.            |
| Horizontal Stacked Bar Chart | A Horizontal Stacked Bar Chart shows multiple data series stacked within horizontal bars, helping visualize part-to-whole relationships while making long category names easier to read.                           | Use a Horizontal Stacked Bar Chart when you want to compare totals across categories and also see how each part contributes—especially when category names are long | <p>An example for this is -  showing total sales by region with each bar split into product categories like electronics, clothing, and furniture. </p><p><br></p>                     |
| Line Chart                   | A Line Chart displays data points connected by lines to show how one or more values change over time or across a continuous range, making it ideal for identifying trends and patterns.                            | Use a Line Chart when you want to show how a value changes over time or across a continuous range.                                                                  | An example for this is -  tracking monthly sales throughout the year to see whether they are increasing or decreasing.                                                                |
| Dot Chart                    | A Dot Chart displays numerical values as dots along a common axis, making it a clean and effective way to compare multiple data points across categories, especially when dealing with large or labeled datasets.  | Use a Dot Chart when you want to compare many values across categories in a clean and uncluttered way, especially when labels are long or data points are numerous. | <p>An example for this is -  comparing employee performance scores across multiple departments where each department has several individuals. </p><p><br></p>                         |
| Bubble Chart                 | A Bubble Chart displays three dimensions of data using the x-axis, y-axis, and bubble size, where the size of each bubble represents a quantitative value, helping compare both position and magnitude.            | Use a Bubble Chart when you want to compare data across two variables and also show a third value through size.                                                     | An example for this is - plotting products by price (x-axis) and sales (y-axis), with bubble size representing profit to quickly see high-performing products.                        |
