### Overview

The **Rediscover** feature allows users to refresh and synchronize the dashboard with the latest changes made to the underlying dataset or data source. It helps identify newly added fields, updated configurations, or structural changes in the dataset and reflects them within the dashboard. This feature ensures that the dashboard remains aligned with the most recent data definitions and prevents inconsistencies caused by outdated metadata. Rediscover helps maintain data accuracy and keeps dashboard components up to date. &#x20;
