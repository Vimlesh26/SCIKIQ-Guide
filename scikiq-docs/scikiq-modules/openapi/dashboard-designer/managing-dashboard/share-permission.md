### Overview

The **Sharing Permissions** feature allows users to control access to dashboards by granting permissions to specific users, groups, or roles. This feature improves security by ensuring that dashboard information is accessible only to authorized users. It also supports collaboration by enabling controlled sharing and access management across teams. &#x20;

***

## Procedure

The below step-by-step instructions help you understand how to share perssions:

1. On the **Dashboard List page**, click the **Permission** icon corresponding to the required dashboard.

<img src="../../../../.gitbook/assets/unknown (251).png" alt="Dashboard List - Permission Icon" height="288" width="624">

The Resource Permission dialogue box is displayed.

2. On the **Resource Permission** dialogue box:

* Select the required permission choosing from **Public, Private,** and **Shared**.
* Click the **Save** button.

See the below image.

![Dashboard List - Resource Permission Dialogue Box](<../../../../.gitbook/assets/unknown (252).png>)

The Permission is granted successfully.
