### Overview

The **Switch Version** feature allows navigating between different versions of a dashboard and view previously saved configurations or updates. It helps track changes made over time and provides the flexibility to access earlier versions when required. This feature supports version management by enabling users to compare modifications and maintain consistency across dashboard updates. It also helps reduce the risk of losing important configurations by preserving historical versions.

***

## Procedure

The below step-by-step instructions help you understand how to switch versions:

1. On the **Dashboard List** page, select the required **version** from the Version drop-down box corresponding to the required dashboard.

![Dashboard List - Version Drop-Down Box](<../../../../.gitbook/assets/unknown (279).png>)

The Version Change Confirmation message box is displayed.

2. On the **Version Change Confirmation** message box, click the **Yes** button.

![Dashboard List - Version Change Confirmation Message Box](<../../../../.gitbook/assets/unknown (280).png>)
