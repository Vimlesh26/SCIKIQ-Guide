### Overview

The **Show Deleted Resources** feature allows viewing dashboards or related resources that have been deleted from the system. It helps tracking removed resources and provides visibility into previously deleted items for auditing and management purposes. This feature can assist in identifying resources that were deleted accidentally or reviewing historical dashboard information. It also helps maintain better control and monitoring of dashboard lifecycle activities.

***
