### About Dashboard Designer

{% tabs %}
{% tab title="Overview" %}
The **SCIKIQ Dashboard Designer** enables you to create interactive dashboards that present key business insights in a single view. Dashboards consist of various components, such as charts, tables, and other widgets, that visually represent data from connected datasets and data sources.&#x20;

You can use filters and parameters to refine the displayed information based on specific requirements.&#x20;

Dashboards can also be configured to refresh automatically or manually, ensuring that the latest data is always available. A flexible layout helps organize components in a clear and visually appealing manner, making dashboards easy to read and analyze.
{% endtab %}
