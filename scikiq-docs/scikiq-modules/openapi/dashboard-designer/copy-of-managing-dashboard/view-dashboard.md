### Overview

The **View Dashboard** feature allows users to access and interact with a dashboard after it has been created and published. It provides a consolidated view of charts, widgets, tables, and other visual components configured within the dashboard. Users can analyze data, apply filters, interact with visualizations, and gain insights based on the displayed information. This feature helps users monitor key metrics and make informed decisions through an interactive and user-friendly interface. &#x20;

***

## Procedure

The below step-by-step instructions help you understand how to view dashboard:

1. On the **SCIKIQ left navigation bar,** click **Dashboard List** under **SCIKIQ CONSUME**.

<img src="../../../../.gitbook/assets/unknown (275).png" alt="Dashboard List Menu Item" width="521">

The Dashboard List page is displayed.

2. On the **Dashboard List page**, click the **View** icon corresponding to the required dashboard.

<img src="../../../../.gitbook/assets/unknown (276).png" alt="Dashboard Dashboard List - View Icon" width="563">

The dashboard is displayed. See the below example image.
