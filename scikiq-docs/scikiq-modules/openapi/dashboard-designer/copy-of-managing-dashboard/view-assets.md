### Overview

The **View Assets** feature allows users to access and view assets that have been created from dashboards or related resources. It provides a centralized location to manage and review available assets for reuse across different modules or applications. This feature helps improve resource organization, enhances accessibility, and reduces duplication by allowing users to leverage existing assets. It also supports efficient management and utilization of dashboard-related components.

***

## Procedure

The below step-by-step instructions help you understand how to view assets:

* On the **Dashboard List** page, enable the **Show Assets** option on the top.

The available assets are displayed. If no assets are available, then “No data available in table” message is displayed. See the below example image.
