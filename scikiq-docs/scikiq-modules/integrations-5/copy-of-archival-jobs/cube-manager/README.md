### Overview

This page provides a brief overview of **Cube Manager**, its role in the **Archival** process, and the key tasks that can be performed in Cube Manager.

Expand the panels below to view detailed information about each topic.

<details>

<summary><strong>What is a Cube Manager?</strong></summary>

**Cube Manager** is a component of the Archival module used to **create, configure, manage, and maintain data cubes associated with archived data**.

A **data cube** organizes data into **dimensions and measures**, allowing large volumes of archived data to be structured for efficient exploration, filtering, aggregation, and analysis. For example, archived transaction data could be analyzed by dimensions such as **date, customer, product, or region**, with measures such as **transaction count or amount**.

</details>

<details>

<summary><strong>Role of Cube Manager in Archival</strong></summary>

In an archival environment, Cube Manager helps make archived data **more usable and accessible for analysis** after it has been moved to archival storage. Its role typically includes:

**1. Create and configure cubes**\
Users can add a cube and define the data and configuration required for analytical use.

**2. Manage existing cubes**\
Users can view cube details and configuration and update them when required.

**3. Keep cubes in sync with source data**\
The **Re-ingest** capability can be used to ingest the relevant source data into the cube again when required.

**4. Examine source data**\
The **Investigate Source** capability helps users inspect or understand the source data associated with a cube.

**5. Support reporting and monitoring**\
Users can view cube-related information and download a **Summary Report** for reference or further analysis.

</details>
