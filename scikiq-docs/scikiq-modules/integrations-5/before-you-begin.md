# Before You Begin

***

### Overview

This page describes the essential prerequisites for using a **SCIKIQ** product. It outlines the login requirements, the permissions needed to access various features, and the required administrator settings that must be configured before you begin. Reviewing these prerequisites helps ensure that you have the necessary access and system configuration to use the application effectively.

***

### Requirements

Click on the below tabs to view detailed information.

{% tabs %}
{% tab title="Prerequisites" %}
Before you begin, ensure that:

* You are logged in to **SCIKIQ**.
* You have access to the required workspace, project, or environment, if applicable.
* Any prerequisite resources, connections, or configurations required for this module have already been created.
* You have the necessary permissions to perform the required actions.
{% endtab %}

{% tab title="Login Requirements" %}
The following are the login requirements for accessing the application.

* Have a valid SCIKIQ user account.
* Log in using your assigned username/email address and password.
* Access the SCIKIQ application through the appropriate environment URL.
* Use a supported web browser (Google Chrome is recommended).
{% endtab %}

{% tab title="System Requirements" %}
The below are the system requirements:

* Active access to the SCIKIQ platform
* Administrative privileges
* Valid database connection details
* Network connectivity between SCIKIQ and AWS
{% endtab %}

{% tab title="Cloud Requirements" %}
An AWS account enables with the following services:

* Amazon S3
* IAM Roles
* CloudWatch Monitoring
* Lifecycle Policies
{% endtab %}

{% tab title="Required Permissions" %}
Your access to and use of this module is determined by the permissions assigned to your user account. Before using this module, ensure that:

* You have permission to access the module.
* An appropriate role has been assigned to your account.
* You have the required permissions to perform actions such as viewing, creating, editing, deleting, or managing records, based on your assigned role.

> <mark style="color:red;">**Note:**</mark> The available actions may vary based on your assigned role and permissions.
{% endtab %}
{% endtabs %}
