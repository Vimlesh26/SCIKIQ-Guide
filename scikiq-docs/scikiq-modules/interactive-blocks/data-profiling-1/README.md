### Overview

{% tabs %}
{% tab title="What is Data Profiling?" %}
Data profiling examines and analyzes data to evaluate its structure, content, and quality. It helps identify issues such as missing values, duplicate records, inconsistent data, and invalid formats, enabling you to assess data quality before it is used for analysis or downstream processes.
{% endtab %}

{% tab title="Why Data profiling needed?" %}
Data profiling is essential for understanding, assessing, and improving data quality. It helps identify data issues at an early stage, supports data integration and analysis, ensures compliance with organizational standards, and enables informed decision-making.&#x20;

By detecting inconsistencies and quality gaps before the data is used, data profiling reduces rework, saves time and resources, and plays a vital role in effective data management across organizations.
{% endtab %}

{% tab title="Data profiling in SCIKIQ " %}
In ScikIQ, the **Data Profiling** feature enables you to explore data, validate it against existing metadata, and identify data quality issues and gaps in data artifacts, including logical models, physical models, DDL, and model descriptions.

The **Data Profiling** feature provides the following capabilities:

* Perform Exploratory Data Analysis (EDA) to understand data characteristics.
* Create and manage multiple versions of a table.
* Prepare and customize data for model training.
* Deploy trained models to process and analyze new data.
{% endtab %}
