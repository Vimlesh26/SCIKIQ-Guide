# SCIKIQ CURATE

SCIKIQ Curate is an advanced data management platform designed to enhance data curation processes with AI, machine learning, and integrated data governance practices. It offers a range of tools to streamline data operations, ensuring quality and compliance.

**Key Features**

* **Data Prep Studio**: Accepts data in various formats (database, files, queries, SAP apps) and supports multiple transformations such as filtering, ordering, grouping, and value mapping.
* **Logical and Business Data Modeling**: Create robust data models that integrate seamlessly across numerous data sources.
* **Orchestrator and Schedules**: Coordinate and automate data workflows effectively for timely data management.
* **Advanced Functions**: Perform complex transformations including comparisons, logical operations, statistical, and mathematical functions.
* **Joins**: Build comprehensive data models by joining tables from multiple sources with ease.

With SCIKIQ Curate, organizations can bridge communication gaps and optimize their data assets to drive strategic decision-making.
