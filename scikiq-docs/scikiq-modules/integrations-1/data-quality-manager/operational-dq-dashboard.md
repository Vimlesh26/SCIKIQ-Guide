# Operational - DQ Dashboard

* The Data Quality Dashboard enables data stewards and business users to continuously monitor data quality, view its current state, track trends, and use this insight to make informed business decisions, the operational dashboard helps track problems to source by drilling down to original records, and quickly understand the cause of invalid data.
*   This dashboard helps answer the below data observatory questions:

    * Freshness - Is the data up-to date or are there any gaps where data has not been updated
    * Distribution - Is the data within expected ranges
    * Volume - is the data intake meeting expected thresholds
    * Schema - Identify change in formal structure of data management system


* DQ dashboard is accessible to Data Analysts. This is an operational dashboard for the deep dive into any inconsistencies in the actual records that have failed, to understand the issue and do a root cause analysis. This gives a complete consolidated 360-degree view of data quality checks applied on table, result-set, trends and details of exceptions.
