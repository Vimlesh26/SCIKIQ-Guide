# Dashboard

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

This page describes how to use the **Dashboard** to manage parsed reports. The Dashboard displays all the reports from which metadata has been extracted. You can view and edit the metadata of a selected report, submit it for approval, or delete the report as required.

***

### Managing Metadata

You can manage extracted metadata by viewing, editing, deleting, or submitting it for approval.

Click the tabs below for step-by-step instructions on each task.

{% tabs %}
{% tab title="Viewing Metadata " %}
**Overview**

This section describe how to view metadata details. **Viewing metadata details** enables to review the metadata extracted from a report, verify the available information, and identify any required modifications before submitting it for approval.

**Procedure**

The below instructions help you understand how to view the metadata of a report.

_**To view the metadata**_ _**details of a report**_

{% stepper %}
{% step %}
**Navigate to Dashboard**

1. On the **SCIKIQ Left Navigation Bar**, go to **SCIKIQ Control**, and then expand **Meta Data Manager**.

The Meta Data Manager menu is displayed.

2. On the **Meta Data Manager** menu, click **PowerBI Parser**, and then select **Dashboard.**

<figure><img src="../../../.gitbook/assets/image (3087).png" alt=""><figcaption></figcaption></figure>

The **Dashboard** is displayed.
{% endstep %}

{% step %}
**View Metadata Details**

* On the **Dashboard** page, click the **View Details** icon corresponding to the required report.

The **Dashboard Metadata Details** screen is displayed. See the below example image.

{% tab title="Updating Metadata" %}
**Overview**

This section describe how to update the metadata. **Updating metadata** helps to correct inaccurate or incomplete information, update details to reflect business requirements, and ensure that the extracted metadata is accurate and consistent before submitting it for approval.

**Procedure**

The below instructions help you understand how to update the metadata of a report.

_**To update the metadata**_&#x20;

> <mark style="color:red;">**Note:**</mark> You can edit metadata only when its status is **Draft** or **Submitted**. Metadata in **Approval Pending** or **Approved** status cannot be edited.

{% stepper %}
{% step %}
**Navigate to Dashboard**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>Dashboard.

The Dashboard is displayed.
{% endstep %}

{% step %}
**Edit Metadata**

1. On the **Dashboard** page, click the **Edit** icon corresponding to the report.

<figure><img src="../../../.gitbook/assets/image (3090).png" alt=""><figcaption></figcaption></figure>

The **Edit Dashboard** dialogue box is displayed.

2. On the **Edit Dashboard** dialogue box, make the required changes to **description,** and then click the **Save** button.

<figure><img src="../../../.gitbook/assets/image (3091).png" alt=""><figcaption></figcaption></figure>

The description is updated. See the below image.

<figure><img src="../../../.gitbook/assets/image (3092).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Sending Metadata for Approval" %}
**Overview**

This section describe how to submit metadata for approve. **Sending metadata for approval** enables designated approvers to review and validate the extracted metadata before it is approved for use.&#x20;

This helps ensure that the metadata meets business requirements and organisational standards.any required modifications before submitting it for approval.

**Procedure**

The below instructions help you understand how to submit the metadata for approval.

_**To submit the metadata for approval**_

{% stepper %}
{% step %}
**Navigate to Dashboard**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>Dashboard.

The **Dashboard** page is displayed.
{% endstep %}

{% step %}
**Send for Approval**

1. On the **Dashboard** page, click the **Send for Approval** icon corresponding to the required report.

<figure><img src="../../../.gitbook/assets/image (3093).png" alt=""><figcaption></figcaption></figure>

The **Send Selected Report(s) for Approval** screen is displayed.

2. On the **Send Selected Report(s) for Approval** screen, select the **Approver** from the **User** drop-down box, and then click the **Send for Approval** button.

<figure><img src="../../../.gitbook/assets/image (3094).png" alt=""><figcaption></figcaption></figure>

The metadata is submitted for approval and the status is displayed as **Pending**.

<figure><img src="../../../.gitbook/assets/image (3095).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Deleting Metadata" %}
**Overview**

This section describes how to delete metadata from SCIKIQ. **Deleting metadata** enables you to remove information that is incorrect, duplicated, obsolete, or no longer required.&#x20;

This helps maintain an organised metadata repository and prevents the use of outdated or irrelevant information.

**Procedure**

The below instructions help you understand how to delete the metadata.

_**To delete the metadata**_

> <mark style="color:red;">**Note:**</mark> You can delete metadata only when its status is **Draft** . Metadata in **Submitted**, **Approval Pending** or **Approved** status cannot be edited.

{% stepper %}
{% step %}
**Navigate to Dashboard**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>Dashboard.

The **Dashboard** page is displayed.
{% endstep %}

{% step %}
**Delete Metadata**

1. On the **Dashboard** page, click the **Delete** button corresponding to the required report.

<figure><img src="../../../.gitbook/assets/image (3096).png" alt=""><figcaption></figcaption></figure>

The **Bulk Actions** message box is displayed.

2. On the **Bulk Actions** message box, click the **Yes** button.

<figure><img src="../../../.gitbook/assets/image (3097).png" alt=""><figcaption></figcaption></figure>

The metadata is deleted.
{% endstep %}
{% endstepper %}
{% endtab %}
