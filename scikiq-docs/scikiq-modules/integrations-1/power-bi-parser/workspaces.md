# Workspaces

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

This page describes how to manage the Workspaces feature. The Workspaces feature provides a holistic view of number of **Total Workspaces, Total Reports, Synced Workspaces and Not Synced Workspaces.** It also enables to view the reports the required workspace and also download the workspaces in Microsoft XLS format.

***

### Managing Workspaces

{% tabs %}
{% tab title="Viewing Workspace Reports" %}
**Overview**

This section describes how to view workspace reports. **Viewing the reports associated with a workspace** helps to identify and access the reports available within that workspace, enabling to understand its contents and locate relevant reports for analysis.

**Procedure**

**Viewing a workspace report** involves the following steps: Navigating to the Workspaces page, Viewing workspace reports, Opening the report in Power BI, and Sending the request to the report owner.

Follow the step-by-step instructions below to view the workspace report:

_**To view workspace reports**_

{% stepper %}
{% step %}
**Navigate to Workspace page**

1. On the **SCIKIQ Left Navigation Bar**, go to **SCIKIQ Control**, and then expand **Meta Data Manager**.

The Meta Data Manager menu is displayed.

2. On the **Meta Data Manager** menu, click **PowerBI Parser**, and then select **Workspaces**.

<figure><img src="../../../.gitbook/assets/image (3170).png" alt=""><figcaption></figcaption></figure>

The **Workspaces** page is displayed.   &#x20;
{% endstep %}

{% step %}
**View Workspace reports**

* On the **Workspaces** page, click the **View Reports** icon corresponding to the required workspace.

<figure><img src="../../../.gitbook/assets/image (3171).png" alt=""><figcaption></figcaption></figure>

The **Workspaces Reports** screen is displayed.
{% endstep %}

{% step %}
**View the report in PowerBI**

* On the **Workspaces Reports** screen, click the **Open Report in PowerBI** icon corresponding to the required report.

<figure><img src="../../../.gitbook/assets/image (3172).png" alt=""><figcaption></figcaption></figure>

The report is opened in Power BI. .

The **Let's get you permission to view this report** message is displayed.
{% endstep %}

{% step %}
**Send the request to Report Owner**

* On the **Let's get you permission to view this report** message, click the **Send Request** button.

<figure><img src="../../../.gitbook/assets/image (3173).png" alt=""><figcaption></figcaption></figure>

The request is sent to the report owner.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Downloading Workspaces " %}
**Overview**

This section describes how to download workspace reports. **Downloading workspace reports** enables users to save reports locally for offline access, sharing, and further analysis, depending on the supported download format.

**Procedure**

**Downloading a workspace report** involves the following steps: navigating to the Workspaces page and downloading the workspace reports.&#x20;

Follow the step-by-step instructions below to downloads workspace reports:

_**To downloads workspace reports**_

{% stepper %}
{% step %}
**Navigate to Workspace page**

SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>Workspaces page.
{% endstep %}

{% step %}
**Download Workspaces**

On the **Workspaces** page, click the **Export Data** button.

<figure><img src="../../../.gitbook/assets/image (3175).png" alt=""><figcaption></figcaption></figure>

The workspaces are downloaded in XLSX format. See the below example image.&#x20;

<figure><img src="../../../.gitbook/assets/image (3176).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}
