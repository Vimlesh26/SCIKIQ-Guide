# Jobs

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

The **Jobs** page displays all the workspaces submitted for parsing through the Online Parser, along with their current status. Initially, each workspace is marked as **Queued**. Once parsing is complete, its status changes to **Completed**, allowing you to view the extraction summary.

***

### Viewing Metadata Extraction Summary

The extraction summary provides an overview of the Power BI components identified during parsing, including **Tables, Columns, Measures, Visuals, Pages, Filters, Datasets, Reports, and Workspaces**. This information helps users assess the scope of the extracted metadata, understand the composition of the parsed workspace, and verify the results of the parsing proces**s.**

**Procedure**

Follow the step-by-step instructions below to parse the selected workspace reports.

_**To view extraction summary**_

{% stepper %}
{% step %}
**Navigate to Jobs page**

> <mark style="color:red;">**Note:**</mark> The Jobs page is displayed automatically after you submit a workspace for parsing. 1. On the **SCIKIQ Left Navigation Bar**, go to **SCIKIQ Control**, and then expand **Meta Data Manager**.

The Meta Data Manager menu is displayed.
