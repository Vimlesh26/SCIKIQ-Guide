# KPIs

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

This page describes how to manage KPIs in SCIKIQ. A KPI (Key Performance Indicator) is a measurable value used to evaluate how effectively an organization, business unit, or process is achieving its objectives.

***

### Managing KPIs

As part of KPI management, you can view KPI details, update its information, map it to relevant domains and glossary terms, submit it for approval, or delete it when it is no longer required.

Click the tabs below for step-by-step instructions on each task.

{% tabs %}
{% tab title="Viewing  a KPI Details" %}
**Overview**

This section describes how to view the details of a KPI. **Viewing KPI details** allows to review the information associated with a key performance indicator, including its definition and other configured metadata.&#x20;

This helps users understand the KPI's purpose, verify its accuracy, and assess its relevance to business objectives.

**Procedure**

The below instructions help you understand how to view a KPI details.

_**To view a KPI details**_

The Meta Data Manager menu is displayed.

{% tab title="Updating a KPI" %}
**Overview**

This section describes how to update a KPI. **Updating a KPI** allows to modify its existing details to reflect changes in business requirements, performance measurement criteria, or associated metadata. This helps maintain accurate, relevant, and up-to-date KPI information.

**Procedure**

> <mark style="color:red;">**Note:**</mark> You can update a KPI only when its status is **Draft** or **Submitted**. A measure in **Approval Pending** or **Approved** status cannot be edited.

The below instructions help you understand how to update a KPI.

_**To update a KPI**_&#x20;

{% stepper %}
{% step %}
**Navigate to KPIs**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>KPIs.
{% endstep %}

{% step %}
**Edit KPI**

1. On the **KPI List** page, click the **Edit** icon corresponding to the required KPI.

<figure><img src="../../../.gitbook/assets/image (3138).png" alt=""><figcaption></figcaption></figure>

The **Edit KPI** dialogue box is displayed.

2. On the **Edit KPI** dialogue box, make the required change&#x73;**,** and then click the **Save** button.

<figure><img src="../../../.gitbook/assets/image (3139).png" alt=""><figcaption></figcaption></figure>

The KPI is updated.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Mapping Domains/Glossaries" %}
**Overview**

This section describe how to map the domains/glossaries. **Mapping domains and glossary terms to KPIs** allows to associate key performance indicators with relevant business domains and standardized business terminology.&#x20;

This helps organize KPIs by business area, establish consistent definitions, improve discoverability, and ensure that KPIs align with the organization's business context and terminology.

**Procedure**

The below instructions help you understand how to update a procedure/domain.

_**To map a domain/glossary**_

{% stepper %}
{% step %}
**Navigate to KPIs**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>KPIs.

The **KPI List** page is displayed.
{% endstep %}

{% step %}
**Map Domain/Glossary**

1. On the **KPI List** page, click the **Map Domains/Glossaries** icon corresponding to the required KPI.

<figure><img src="../../../.gitbook/assets/image (3143).png" alt=""><figcaption></figcaption></figure>

The **Map Domains / Glossaries - Total workspaces** dialogue box is displayed.

2. On the **Map Domains / Glossaries - Total workspaces** dialogue box, select the **domain and glossary (optional),** and then click the **Save Mapping** button.

> <mark style="color:red;">**Note:**</mark> If you want to delete an existing mapping, then click the **Remove Mapping** button corresponding to it in the **Existing Mappings** section. See the below image.

<figure><img src="../../../.gitbook/assets/image (3144).png" alt=""><figcaption></figcaption></figure>

The domain is mapped. See the below image.

<figure><img src="../../../.gitbook/assets/image (3145).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Sending for Approval" %}
**Overview**

This section describes how to send a KPI for approval. **Sending a KPI for approval** allows to submit its details and associated metadata to the designated approver for review.&#x20;

This helps validate the KPI's accuracy, consistency, and alignment with business requirements before it is approved for use.

**Procedure**

The below instructions help you understand how to send a KPI for approval.

_**To send a KPI for approval**_

{% stepper %}
{% step %}
**Navigate to KPI List Page**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>KPIs.

The **KPI List** page is displayed.
{% endstep %}

{% step %}
**Send for Approval**

1. On the **KPI List** page, click the **Send for Approval** icon corresponding to the required KPI.

<figure><img src="../../../.gitbook/assets/image (3146).png" alt=""><figcaption></figcaption></figure>

The **Send Selected Report(s) for Approval** screen is displayed.

2. On the **Send Selected KPI(s) for Approval** screen, select the **Approver** from the **User** drop-down box, and then click the **Send for Approval** button.

<figure><img src="../../../.gitbook/assets/image (3147).png" alt=""><figcaption></figcaption></figure>

The KPI is submitted for approval and the status is displayed as **Auto Approved**.

<figure><img src="../../../.gitbook/assets/image (3148).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Deleting a KPI" %}
**Overview**

This section describes how to delete a KPI from SCIKIQ. **Deleting a KPI** allows users to remove performance indicators that are no longer required or relevant to business objectives.&#x20;

This helps maintain an accurate and organized KPI repository by eliminating obsolete or unnecessary KPI definitions.

**Procedure**

The below instructions help you understand how to delete a KPI.

_**To delete a KPI**_

> <mark style="color:red;">**Note:**</mark> You can delete a KPI only when its status is **Draft** . A KPI in **Submitted**, **Approval Pending** or **Approved** status cannot be deleted.

{% stepper %}
{% step %}
**Navigate to KPI List Page**

* SCIKIQ Left Navigation Bar>>SCIKIQ Control>>Meta Data Manager>> PowerBI Parser>>KPIs.

The **KPI List** page is displayed.
{% endstep %}

{% step %}
**Delete KPI**

1. On the **KPI List** page, click the **Delete** button corresponding to the required KPI.

<figure><img src="../../../.gitbook/assets/image (3140).png" alt=""><figcaption></figcaption></figure>

The **Delete KPI** message box is displayed.

2. On the **Delete KPI** message box, click the **Yes** button.

<figure><img src="../../../.gitbook/assets/image (3142).png" alt=""><figcaption></figcaption></figure>

The KPI is deleted.
{% endstep %}
{% endstepper %}
{% endtab %}
{% endtabs %}
