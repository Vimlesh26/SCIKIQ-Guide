### Overview

This page describes how to use the Power BI Parser. A **Power BI Parser** is a software component that reads and analyzes Power BI reports and supported files to extract their metadata.&#x20;

The extracted metadata helps organize and catalog Power BI assets, understand data relationships, and improve data discovery and governance. It also enables users to gain insights into how reports are structured and which data sources support them.

***

### Power BI Modules

The Power BI Parser provides features for managing workspaces, parsing Power BI assets, monitoring jobs, viewing dashboards, and exploring table metadata, table relationships, column metadata, measures, and KPIs. Here is a brief description of each of these:

The following table provides brief descriptions of the features available under the Power BI Parser in SCIKIQ.

| Feature                           | Description                                                                                                                      |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Workspaces                        | Enables users to view and manage Power BI workspaces that organize related reports, dashboards, and other assets.                |
| Online Parser                     | Enables users to parse Power BI assets online to extract their structure and metadata, depending on the supported configuration. |
| Jobs                              | Allows users to view and monitor parsing jobs and track their execution status.                                                  |
| Dashboard                         | Provides an overview of Power BI parsing activities and related information through a centralized interface.                     |
| Table Metadata                    | Displays metadata about tables, including table names and other available properties extracted from Power BI assets.             |
| Table Relationships               | Displays relationships between tables to help users understand how data is connected within a Power BI data model.               |
| Column Metadata                   | Displays information about table columns, such as column names, data types, and other available properties.                      |
| Measures                          | Displays measures defined using DAX to perform calculations, such as total sales, average revenue, and profit margin.            |
| KPIs (Key Performance Indicators) | Displays configured indicators used to measure and monitor performance against defined business objectives or targets.           |
