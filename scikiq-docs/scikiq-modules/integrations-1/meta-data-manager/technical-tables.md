# Technical Tables

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

This page describes how to manage technical tables. Technical tables in metadata are database tables that store information about the structure, configuration, and properties of data within a system. They describe how data is organized and managed rather than the business meaning of the data itself.

***

### Managing Technical Tables

As part of managing **technical tables**, you can perform the following tasks:

* **Viewing Technical Table Details:** As part of this, you can view the table's metadata, including its structure, schema, and associated properties, to understand how the table is defined and configured.
* **Updating Technical Table:** As part of this, you can modify the table's name and description.
* **Sending Technical Table for Review:** As part of this, you can submit the technical table's metadata for review and validation by designated reviewers before approval.

Click the below tabs to view step-by-step instructions for each of the above mentioned tasks.

{% tab title="Viewing Table Details" %}
**Overview**

This section describes how to view a technical table details.**Viewing technical table details** helps to understand the table's structure, schema, columns, data types, and other associated metadata. This enables verifying table configurations, identify relevant data elements, and understand how the table is organized before performing data management or related operations.

**Procedure**

The below instructions help you understand how to view table details:

_**To view table details**_

1. Navigate to **Technical Tables** page. (SCIKIQ Left Navigation Bar>> SCIKIQ Control>>Meta Data Manager>>Technical Tables)

The **Technical Tables** page is displayed.

2. On the **Technical Tables** page, click the **View Table Details** icon corresponding to the required technical table.

The Table Details screen is displayed.&#x20;

{% tab title="Updating a Technical Table" %}
**Overview**

This section describes how to update a technical table. **Updating table details** allows to modify table **name and description.** This is useful when correcting inaccurate information, updating table descriptions, or maintaining accurate metadata for effective data management and cataloging.

**Procedure**

The below instructions help you understand how to update a technical table details:

_**To view table details**_

1. Navigate to **Technical Tables** page. (SCIKIQ Left Navigation Bar>> SCIKIQ Control>>Meta Data Manager>>Technical Tables)/

2. On the **Technical Tables** page, click the **View Table Details** icon corresponding to the required technical table.
