# Explore Meta Data

### <mark style="color:blue;">Overview</mark>

The **Explore Metadata Submodule** is designed to help users easily access, search, and export metadata from various connected data sources. It provides a centralized interface where you can view all available connections, explore their tables, and work with metadata efficiently.

### <mark style="color:blue;">How to Use the Explore Metadata</mark>

#### Access the Explore Metadata Submodule

* Navigate to the **Explore Metadata** submodule from the main menu.
* Upon entering, you will see a list of all connected source connections.

#### View Connected Sources

* The submodule displays all the connected data sources grouped by their connection types.
* You can select any source connection from the list to explore its metadata.

#### Search Connections

* A **search bar** is available to quickly find a specific connection by name.
* Simply type your query, and the list will filter accordingly.

#### Understand the Search List Display

* Below the search bar, a **Search list** shows grouped connection types.
* The groups allow you to filter connections based on their **Connection Type**.

#### Select a Group to Filter Connections

* Click any group name (for example, **Relational Database**) to filter the list and display only connections belonging to that group.
* This helps narrow down your search for the specific type of data source you want to explore.

#### Search Within Selected Group

* After selecting a group, use the search bar to find specific connections by name.
* The list will dynamically update as you type.

#### Select a Connection

* Clicking on a connection highlights it and displays the list of tables related to that connection on the right side.
* You can scroll through the tables and select the one you want to inspect.

#### View Resource Details

* After selecting a table, click **Continue** or **Next** to navigate to the **Resource Details** screen.
*   Here, you can:

    * View detailed metadata information about the selected table.
    * Refresh or reload metadata if needed.



Navigate to the Detailed Page

* After selecting a connection from the list, a **popup appears** asking you to **Select Industry and Domain**.

#### Select Industry and Domain

* In the popup, use the dropdown to:
  * **Select Industry** (e.g., Finance, Healthcare, etc.)
  * **Select Domain** (e.g., Customer Journey, Operations, etc.)
* After making selections, click the **Save** button.

#### Access the "All" Tab & Reclassify Tables

* Once saved, go to the **"All" tab** on the detailed page.
* Click on **Reclassify Table** button.
* This triggers a classification of the tables into different categories like:  \
  Default  \
  Operations Journey  \
  Customer Journey  \
  Governance Journey  \
  Product Journey

#### Map Data to Business Journey (Optional)

* A checkbox prompt appears asking:\
  _“Do you want to Map Data to Business Journey that have not been Mapped?”_
* Check this box if you want to map unmapped data.
* Click **Confirm** or **Yes**.

#### Get Data Product Use Case

* Click on the **Get Data Product Use Case** button.
* The system displays the relevant use cases according to the reclassified tables.
* These use cases reflect how tables link to business processes or insights.
