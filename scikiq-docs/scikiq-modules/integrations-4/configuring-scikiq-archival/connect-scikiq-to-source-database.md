## Overview

The purpose of connecting the application with the Source Database while configuring the archival process is to establish secure access to the original data so it can be identified, filtered, and archived accurately. The process consists of the following steps: Select a New Data Source, Configure Connection Details, Add Metadata, Discovery, Configuration, and Review & Submit.&#x20;
