# Configuring SCIKIQ Archival

## Overview

Configuring SCIKIQ Archival is a structured process that involves a series of well-defined steps to ensure efficient data management, compliance, and secure storage. The process begins with connecting SCIKIQ to the source database, enabling access to the data that needs to be archived.

Once the connection is established, table classification is configured to identify and categorize data based on its relevance and usage. This is followed by setting up the appropriate compliance framework to align with regulatory and organizational requirements. Based on the selected framework, a compliance policy is created to define rules for data retention, archival, and deletion.

Next, the AWS setup is configured to establish the storage environment for archived data. After this, an archival job is created to define how and when data should be moved from the source system to archival storage. The configuration is then deployed to activate the defined settings and initiate the archival process.

Finally, SCIKIQ provides options to view the archived data for retrieval and analysis, as well as to delete data when it is no longer required, ensuring complete lifecycle management of archived information.
