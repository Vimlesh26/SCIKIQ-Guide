### **Overview**

The **Saved FBDI Configurations** screen displays a list of all previously created FBDI configurations within the SCIKIQ application.

This screen allows users to manage, review, and reuse existing configurations without needing to recreate them from scratch.

Using this screen, users can:

* View all saved configurations
* Search and filter configurations
* Edit existing configurations
* Clone configurations for reuse
* Delete configurations if no longer required
* Execute previously saved FBDI jobs

This helps improve efficiency and ensures consistency in data migration processes.

***

### **Procedure**

Follow the steps below to use the Saved FBDI Configurations screen:

#### **1. Access the Screen**

* Log in to the SCIKIQ application
* Navigate to **Saved FBDI Configurations** from the menu

***

#### **2. View Configurations**

* A list/grid of saved configurations is displayed
* Typical details include:
  * Configuration Name
  * Description
  * Template Used
  * Source and Target Connections
  * Status (Active/Inactive/Last Run Status)
  * Created/Modified Date

***

#### **3. Search and Filter**

* Use the search bar to find a specific configuration
* Apply filters based on:
  * Name
  * Status
  * Date
  * Template

***

#### **4. View Configuration Details**

* Click on a configuration name to open detailed view
* Review:
  * Selected template
  * Table mappings
  * Field mappings
  * Relationships

***

#### **5. Edit Configuration**

* Select a configuration and click **Edit**
* Modify required details such as:
  * Connections
  * Table selection
  * Field mappings
* Save the changes

***

#### **6. Clone Configuration**

* Select an existing configuration
* Click **Clone** to create a copy
* Update necessary details and save as a new configuration

***

#### **7. Delete Configuration**

* Select the configuration
* Click **Delete**
* Confirm deletion

***

#### **8. Execute Configuration**

* Select a configuration
* Click **Run/Execute**
* Monitor job execution and status

[^1]: **Host Name** refers to the **address** of the computer/server where your database is located.
