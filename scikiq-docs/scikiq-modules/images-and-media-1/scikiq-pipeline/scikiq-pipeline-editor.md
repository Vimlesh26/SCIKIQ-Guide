# SCIKIQ Pipeline Editor

***

### Instructions for Using this Page

* Click on an image to view it in a larger and clearer format.
* The inputs shown in the images are for example purposes only. You must enter the correct and actual data.

***

### Overview

Understanding the parts of an interface helps you use a system **faster, more confidently, and more effectively**. This page helps you understand the parts of **SCIKIQ Pipeline Editor,** which include **Left Pane,  Main Workspace (Center Grid), Top Toolbar,  Side Panel, Bottom Panel,** and **Help Section.**

***

### Parts of Pipeline Editor

<figure><img src="../../../.gitbook/assets/S (250).png" alt=""><figcaption><p>SCIKIQ Pipeline Editor</p></figcaption></figure>

Click on the below tabs to view the description of SCIKIQ Pipeline Editor.

{% tabs %}
{% tab title="1. Left Pane" %}
The **Left Pane** shows the configuration fields for the node selected in the Main Workspace. For example, when you add or select a **Dataset Input** node, its related fields appear in the Left Pane so you can enter and configure the required data.

<figure><img src="../../../.gitbook/assets/S (251).png" alt=""><figcaption><p>Left Pane</p></figcaption></figure>
{% endtab %}

{% tab title="2. Main Workspace (Center Grid)" %}


The **Main Workspace** is the main area where you build your data pipeline. You can **drag and drop** different components like data sources, processing steps, and outputs to create the workflow.&#x20;

**Features of the Main Workspace**

* **Drag and Drop:** Easily move and arrange components
* **Connections:** Link components to show how data flows
* **Visual View:** See the whole pipeline clearly in one place

Apart from the above, you can view **earlier versions of the pipeline** by selecting them from the **Current Version** drop-down in the Main Workspace.

<figure><img src="../../../.gitbook/assets/S (252).png" alt=""><figcaption><p>Main Workspace (Center Grid)</p></figcaption></figure>
{% endtab %}

{% tab title="3. Top Toolbar" %}
The **Top Toolbar** consists of essential tools needed to build your data pipeline. These tools include **Input Nodes, Transform Nodes, Unstructured Nodes, Output Nodes, SQL Stmt, Variable, Advanced Nodes,** and **Admin Controls.**

Click the tabs below to view the description of each node.

{% include "https://app.gitbook.com/s/DNwsZ15QVplELLLQacGt/~/reusable/JySay6kiBxWw4M8ZLwzE/" %}
{% endtab %}

{% tab title="4. Side Panel" %}
The **Side Panel** provides advanced configuration and control settings to optimize data processing tasks. These include **Execution Setting, Node Information, Set Parameter, Job Logs, Database Input Suggestions,** and **Node Validation**.

Click the tabs below to view the description of each these.

{% include "https://app.gitbook.com/s/DNwsZ15QVplELLLQacGt/~/reusable/h8YmQQga9BP5YkyTzvKT/" %}
{% endtab %}

{% tab title="5. Bottom Panel (SQL & Preview Panel)" %}
The **Bottom Panel** panel allows you to inspect your pipeline’s SQL queries and preview intermediate data transformations. It contains two tabs: **SQL** and **Preview**.

Click the tabs below to view the description of each these.

{% include "https://app.gitbook.com/s/DNwsZ15QVplELLLQacGt/~/reusable/6908JT7KxiecteubrPt6/" %}
{% endtab %}

{% tab title="6. Help Section" %}


The **Help section** shows basic information about the node selected in the Main Workspace. For example, when you add or select a **Dataset Input** node, the Help section displays its description. You can view the information for any node simply by clicking on it in the Main Workspace.

<figure><img src="../../../.gitbook/assets/S (253).png" alt=""><figcaption><p>Help Section</p></figcaption></figure>
{% endtab %}
{% endtabs %}
