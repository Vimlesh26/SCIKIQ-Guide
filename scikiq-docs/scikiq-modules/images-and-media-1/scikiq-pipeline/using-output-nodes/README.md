## Overview

**What are output nodes?**

Output nodes act as the final destination in a pipeline and define where and how the processed data is delivered after all input and transformation steps are completed.

**Role of Output Nodes in a Pipeline**

In a pipeline flow, input nodes bring data into the system, transform nodes process the data, and output nodes deliver the final result to the target destination.

Input Nodes → Transform Nodes → Output Nodes

**Using Output Nodes With or Without Transform Nodes**

It is not mandatory to include a transform node every time when connecting an output node to an input node. If no data transformation is required, the output node can be connected directly to the input node. A transform node should be added only when the data needs to be modified, enriched, or restructured before being written to the output.

**Types of Output Nodes**&#x20;

SCIKIQ supports multiple output nodes to meet different data delivery requirements, including: Table Output, File Output, Table Update, Merge, Put API, Kafka Producer, Files to Tables, and Write NoSQL.

> <mark style="color:red;">**Note:**</mark> The functionality of output nodes is common across all pipeline types, including **Delta Pipelines, API Pipelines,** and **Event Pipelines.** You can refer to this page whenever you need to configure output nodes for any of these pipelines.&#x20;
