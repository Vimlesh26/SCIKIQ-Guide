# Event Pipeline

Event Pipelines in SCIKIQ operate on an event-driven architecture, where data processing is initiated by specific triggers or events. These pipelines are designed to manage real-time data flows, allowing systems to respond instantly as new data or signals arrive. They are essential for use cases that demand low-latency, high-frequency data handling to deliver timely insights and responsive user experiences.

### Mandatory Nodes

In SCIKIQ’s Event Pipeline, the Topic Node is a mandatory component. It acts as the primary input for event-driven pipelines, continuously listening to Kafka topics and ingesting data streams in real time. This node can be connected downstream to transformation or analytics nodes, enabling real-time processing and actionable insights
