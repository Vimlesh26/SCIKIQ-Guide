### Overview

This section provides the essential information required to understand the **SCIKIQ Home** page. It includes an overview of the Home page, explains its layout and key components, and describes the purpose of each section. Familiarizing yourself with the Home page will help you navigate the application efficiently and access its features with ease.

### Home Page Description

{% tabs %}
{% tab title="Overview" %}
The **SCIKIQ Home Page** serves as a central dashboard where you can manage your entire data environment from one place. It gives you complete visibility and control over your data assets and governance.

From tracking data catalogs, assets, and domains to managing data pipelines and operations, SCIKIQ makes end-to-end data management simple and efficient. The easy-to-use interface allows you to:

* View reports, schedules, and dashboards
* Receive personalized alerts through notifications and to-do lists
* Quickly locate information using the Advanced Search feature
* Track recent activities and system updates for better visibility

With built-in **ML/GenAI capabilities**, **API integrations**, and **automated workflows**, SCIKIQ helps you streamline data operations, make better decisions, and get maximum value from your data—quickly and effortlessly.
{% endtab %}
