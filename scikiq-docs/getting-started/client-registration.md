# Client Registration

### Client Registration

ScikIQ revolves around the concept of Entities, which serve as both licensing and data organization tools. When a ScikIQ license is sold, it caters to individual corporations or enterprises that consist of multiple legal entities.

<figure><img src="../.gitbook/assets/image (960).png" alt=""><figcaption></figcaption></figure>

2. When a merchant is registered on the ScikIQ Platform, a default user is created for the merchant with the _Client Admin_ role.

<figure><img src="../.gitbook/assets/image (961).png" alt=""><figcaption></figcaption></figure>

3. The user gets an activation mail on registration to activate the account.

<figure><img src="../.gitbook/assets/image (963).png" alt=""><figcaption></figcaption></figure>

4. After activating his/her account merchant must reset his password. The merchant gets an OTP on his mail for this purpose.

<figure><img src="../.gitbook/assets/image (965).png" alt=""><figcaption></figcaption></figure>

5. Once the account has been activated and the password is reset, the merchant can log in into the account using his/her email and password.
6. In ScikIQ email id and password is used for login.

<figure><img src="../.gitbook/assets/image (966).png" alt=""><figcaption></figcaption></figure>

7. On successful login, the user will be shown a landing in ScikIQ.
